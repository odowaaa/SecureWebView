# SomCA Theme — Changelog

## 2.0.0
- **Working newsletter signup**: the footer "Weekly Climate Briefing" form
  now actually submits (AJAX, to SomCA Core 2.0.0's subscriber system)
  with inline success/error messaging instead of doing nothing.
- **Hazard filter** on the Hotspots archive — a dropdown (`?hazard=<slug>`)
  narrows the map/grid to a single hazard type (drought, flood, cyclone…),
  alongside the existing region tabs.
- **CSV export button** on single Hotspot pages, linking to the new
  plugin export endpoint.
- Requires **SomCA Core 2.0.0+**.

## 1.0.0
- Initial release: brand hero, live Leaflet hotspot map, Chart.js trend
  charts, alert banners, and templates for every SomCA content type.
